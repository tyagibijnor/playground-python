# Python Playground

This repository is a small Python learning and practice workspace for experimenting with core programming concepts, data structures, functions, control flow, and file handling.

## Overview

The project contains a collection of beginner-friendly Python scripts designed to practice and reinforce common language features and real-world examples.

## Topics Covered

- Variables and user input
- Arithmetic and conditional logic
- Loops and iteration
- Functions and lambda expressions
- Lists, tuples, sets, dictionaries, and strings
- File reading and writing
- Basic data manipulation and problem-solving exercises

## Project Structure

- `data_operations.py` — list and tuple operations
- `data_structure.py` — Python data structures and examples
- `dictionary.py` — dictionary practice and operations
- `filehandling.py` — reading/writing files and processing contents
- `input_from_user.py` — console input and arithmetic calculator example
- `map_test.py` — `map()` examples and iteration practice
- `Conditional/` — conditionals and looping exercises
- `fun/` — function-based exercises, logical checks, and helper examples
- `example.txt`, `fruits.txt`, `person.txt` — sample data files used by scripts

## Getting Started

Make sure Python 3 is installed on your system.

Run any script like this:

```bash
python3 data_structure.py
```

Or for a function exercise:

```bash
python3 fun/function_test.py
```

## Notes

This repository is intended for learning, experimentation, and hands-on practice rather than production use. You can use it to build confidence with Python basics before moving on to larger projects.
